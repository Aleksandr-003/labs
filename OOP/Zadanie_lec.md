# Практическое задание: «Журнал группы — знакомство со STL»

**Стандарт языка:** C++11 или новее.

## Цель работы

Познакомиться с контейнерами, итераторами и алгоритмами STL. Научиться использовать готовые средства стандартной библиотеки для работы с объектами собственного класса.

## Условие задачи

Разработайте программу «Журнал группы». Она должна хранить имена студентов и их средние баллы, выводить список, находить студента по имени, сортировать записи по успеваемости и подсчитывать отличников.

Меню и ввод с клавиатуры реализовывать не нужно: исходные данные задаются в программе.

## Краткая теория

**STL (Standard Template Library)** — стандартная библиотека шаблонов: набор обобщённых контейнеров, алгоритмов и связанных с ними средств, входящих в стандартную библиотеку C++.

Шаблоны позволяют использовать одни и те же средства для разных типов данных, в том числе для объектов собственных классов.

| Составляющая | Назначение | Используем в работе |
|---|---|---|
| Контейнер | Хранит и организует данные | `std::vector<Student>` |
| Итератор | Позволяет обращаться к элементам контейнера и задавать диапазоны | `begin()`, `end()` |
| Алгоритм | Выполняет типовую операцию над диапазоном элементов | `std::find_if`, `std::sort`, `std::count_if` |

`std::vector` — динамический массив. При добавлении элементов он самостоятельно управляет памятью: вручную создавать новый массив и копировать данные не требуется.

Алгоритмы обычно получают диапазон `[begin(), end())`. Начало входит в диапазон, а конец — нет. `begin()` возвращает итератор на первый элемент непустого контейнера, `end()` — итератор на позицию **за последним элементом**. Разыменовывать `end()` нельзя. У пустого контейнера `begin() == end()`.

В этой работе класс `Student` описывает отдельного студента, контейнер хранит объекты этого класса, а алгоритмы обрабатывают их.

## 1. Изучите и запустите исходную программу

#include <vector>
#include <algorithm>

class Student {
private:
    std::string name;
    double averageGrade;

public:
    Student(const std::string& name, double averageGrade)
        : name(name), averageGrade(averageGrade) {}

    const std::string& getName() const {
        return name;
    }

    double getAverageGrade() const {
        return averageGrade;
    }

    void print() const {
        std::cout << name << ": " << averageGrade << '\n';
    }

int main() {
    std::vector<Student> students{
        {"Анна", 4.7},
        {"Борис", 3.8},
        {"Вера", 4.9},
        {"Глеб", 4.2},
        {"Дарья", 4.6}
    };

        student.print();
    }

    return 0;
}

## 3. Найдите студента по имени

Используйте алгоритм `std::find_if`. Имя для поиска задайте в программе:

```cpp
std::string targetName = "Вера";
```

Дополните заготовку:

```cpp
auto it = std::find_if(
    students.begin(),
    students.end(),
    [&targetName](const Student& student) {
        // верните результат сравнения имени студента с targetName.
    }
);
```

После поиска:

- Если студент найден, выведите его данные с помощью `it->print()`.
- Если студент не найден, выведите сообщение «Студент не найден».

**Подсказка:** если подходящего элемента нет, `std::find_if` возвращает `students.end()`. Прежде чем обращаться к найденному объекту, проверьте результат.

**Проверьте два случая:** имя «Вера» и отсутствующее в списке имя «Иван».

### Как читать заготовку

`auto` означает, что компилятор сам определит тип переменной по её начальному значению. Здесь переменная `it` хранит итератор.

Выражение `[&targetName](const Student& student) { ... }` — **лямбда-функция**. Она задаёт условие поиска и должна возвращать `true` для подходящего элемента и `false` для остальных. Такое условие называется **предикатом**.

- `[&targetName]` позволяет использовать переменную `targetName` из окружающего кода по ссылке.
- `const Student& student` — проверяемый объект, переданный без копирования и без возможности изменить его через этот параметр.
- `it->print()` вызывает метод объекта, на который указывает итератор.

> Заготовки с `TODO` необходимо дополнить перед компиляцией: внутри лямбда-функций должен появиться оператор `return` с логическим выражением.
