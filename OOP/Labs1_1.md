### Создание переменных

Создание простых примитивных типов (например int x = 5) идентично созданиюю и объявлению переменных в С.
Тем не менне С++ добавляет ряд фундаментальных отличий.

Перед использованием любую переменную надо определить. Синтаксис определения переменной выглядит следующим образом:  

```C++
ТИП_ПЕРЕМЕННОЙ имя_переменной;

int age;
double number_1;
```

При определении переменной можно присвоить какое-либо значение.
Присвоение значения начального значения переменной называется ***инициализация***

В С++ есть три вида инициализации:

**Нотация присваивания (assignment notation)** - "классическое" как в языке СИ  
**Функциональная нотация (functional notation)** - в фигурных скобках {}  
**Инициализация в фигурных скобках (braced initialization)** - как вызов функции в круглях скобка ()  

```C++
#include <iostream>

int numberT;
int main()
{
    //Можно так
    int number1 = 10;
    int number2 {20};
    int number3 {20.5}; //Вызовет ошибку!!! 
    //Хотя некоторые компиляторы могут только выдать предупреждение
    //
    int number4 (25);

    //А можно так
    int number5 = 10, number6 {20}, number7 (25);

    int number8 {}; //Тоже самое что int number8 {0};

    int numberT2; // Если переменную не инициализировать, то происходит инициализация по умолчанию
    //ВАЖНО переменная получает значение по умолчанию в зависимости от того где она объявлена

    std::cout << "number1 = "<< number1 << std::endl<<
    "number2 = " << number2 << std::endl << 
    "number4 = " << number4 << std::endl <<
    "number5 = " << number5 << std::endl <<
    "number6 = " << number6 << std::endl <<
    "number7 = " << number7 << std::endl <<
    "nubmer8 = " << number8 << std::endl <<
    "numberT = " << numberT << "Тут будет 0, т.к. объявлена как глобальная" << std::endl <<
    "numberT2 = " << numberT2 << "; - Тут будет мусор" << std::endl;

    return 0;
}
```

### Типы данных в С++

операции с ней можно производить и сколько байт в памяти она будет занимать. В языке C++ определены следующие 
базовые типы данных: логический тип bool, целочисленные типы, типа чисел с плавающей точкой, символьные типы

### Создание переменных c ```auto```

``` auto ``` - Выводит тип объявленной переменной из выражения инициализации.  
Данная возможность появилась в языке с введением стандарта C++11  
Для компиляции программы с указанием стандарта необходимо использовать ключ -std=с++11
