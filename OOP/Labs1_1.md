# Лабораторная работа №1 по ООП

## Основы языка С++

Любая программа на С++ начинается с функции main:
```C++
#include <iostream>

int main()
{
    std::cout << "Hello World!" << std::endl;
    return 0;
}
```


### Создание переменных
Создание простых примитивных типов (например int x = 5) идентично созданиюю и объявлению переменных в С.
Тем не менне С++ добавляет ряд фундаментальных отличий.
