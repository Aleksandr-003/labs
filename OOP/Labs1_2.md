# Лабораторная работа №2 по ООП
Перегрузка функций и методов

Разработать программу согласно номеру варианта, который будет содержать класс со следующими условиями:  
1) Конструкторы 3 шт.   
2) Перегрузку Унарных операций 4 варианта: Постфик/Префикс Инкремент/Декремент
3) Перегрузку Арифметического присваивания: +=,-=,*=,/
4) Перегрузку Бинарных операций: +,-,*,/,<,>,<=,>=,==,!= 
В программе также должно быть:
1 статическое поле
Деструктор отличный от деструктор по умолчанию

Основной функционал программы должен использовать все перегрузки/констукторы из пункто 1-4!

## Важно, в реализации перегрузки бинарных операций +,-,*,/ использовать перегрузки +=,-=,*=,/

Пример:  
```
class GoodExample {
private:
    int value;
public:
    GoodExample(int v = 0) : value(v) {}
    GoodExample& operator+=(const GoodExample& other) {
        value += other.value;
        return *this;
    }
    friend GoodExample operator+(GoodExample lhs, const GoodExample& rhs) {
        lhs += rhs;  // используем существующую логику
        return lhs;
    }
};
 ```
