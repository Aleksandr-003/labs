## Основы работы с PlantUML
### Начало диаграммы:  
    ```plantuml
    plantuml nameDiagramm
    @startuml
        Код диаграммы здесь
    @enduml
    ```

### Простой класс:

    plantuml
    @startuml
        class Person {
        - name: String
        - age: int
        + getName(): String
        + setAge(age: int): void
        }
    @enduml

#### Модификаторы доступа
    + -- public
    - -- private
    # -- protected
    ~ -- package private (Для java)

### Отношения между классами

#### Типы отношений:  
Наследование:  
Наследование - отношение "is-a" (является), где дочерний класс наследует структуру и поведение родительского класса.  

    class Parent  
    class Child  
    Child --|> Parent  

Композиция:  
Композиция - отношение "has-a" (имеет) с сильным владением. Объект-часть не может существовать без объекта-целого.  

    class Engine
    class Car
    Car *-- Engine

Агрегация:  
Агрегация - отношение "has-a" (имеет) со слабым владением. Объект-часть может существовать независимо от объекта-целого.

    class Library
    class Book
    Car o-- Wheel

Ассоциация:  
Ассоциация - структурное отношение между двумя классами, где объекты знают друг о друге и могут взаимодействовать.

    class Doctor  
    class Patient
    class Hospital
    Doctor "1" -- "0..*" Patient : treats
    Patient "1" -- "0..*" Doctor : consults
    Hospital --> Doctor : manages
    Hospital --> Patient : servess

Зависимость:  
Зависимость - отношение использования, где изменение одного класса может повлиять на другой. Временная связь. Один класс например использует другой в качестве параметра.

    Class A
    Class B
    A ..> B

# Сравнительная таблица отношений в ООП

| Отношение | Связность | Время жизни | Направление | C++ реализация |
|-----------|-----------|-------------|-------------|----------------|
| **Наследование** | Очень сильная | Зависимое | Однонаправленное | `class B : public A` |
| **Композиция** | Сильная | Совпадает | Однонаправленное | `A содержит B b;` |
| **Агрегация** | Слабая | Независимое | Однонаправленное | `A содержит B* b;` |
| **Ассоциация** | Средняя | Независимое | Двунаправленное | `A содержит B* b; B содержит A* a;` |
| **Зависимость** | Очень слабая | Временное | Однонаправленное | Параметры, локальные переменные |

## Пояснения к таблице

### Связность
- **Очень сильная**: Тесная связь, изменения в одном классе сильно влияют на другой
- **Сильная**: Классы тесно связаны, но не так сильно как при наследовании
- **Средняя**: Умеренная связь, классы знают друг о друге
- **Слабая**: Минимальная связь, классы слабо зависят друг от друга
- **Очень слабая**: Временная связь только во время выполнения методов

### Время жизни
- **Зависимое**: Время жизни дочернего класса зависит от родительского
- **Совпадает**: Объекты создаются и уничтожаются вместе
- **Независимое**: Каждый объект имеет собственное время жизни
- **Временное**: Связь существует только во время выполнения метода

### Направление
- **Однонаправленное**: Только один класс знает о другом
- **Двунаправленное**: Оба класса знают друг о друге

### C++ реализация
- **Наследование**: Синтаксис наследования классов
- **Композиция**: Прямое включение объекта как члена класса
- **Агрегация**: Хранение указателя на независимый объект
- **Ассоциация**: Взаимные указатели между классами
- **Зависимость**: Использование в параметрах методов и локальных переменных
