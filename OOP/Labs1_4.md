# Лабораторная работа №4 по ООП
Для лабораторной работы №3 оформить иерархию классов как многофайловую программу (если не сделано).   
Разместить объявление и определение каждого класса в отдельных файлах:   `ClassName.h` и `ClassName.cpp`  
Соберите код в:  
1. Cтатическую библиотеку (liblab3.a / lab3.lib),  
2. динамическую библиотеку (liblab3.so / lab3.dll + lab3.lib для импорта на Windows).  
3. Напишите две тестовые программы, каждая из которых использует одинаковый клиентский код, но линкуется с разными библиотеками.

Сборку всех компонентов (библиотек и тестовых программ) выполнить вручную, с использованием прямых вызовов компилятора (g++/clang++). Использование систем автоматической сборки (make, CMake, ninja и др.) не допускается
