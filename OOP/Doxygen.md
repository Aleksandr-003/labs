# Документирование исходного кода с использованием системы doxygen

## О системе
Doxygen — кроссплатформенная система документирования исходных текстов, которая автоматически генерирует документацию на основе комментариев к исходному коду  
Поддерживает языки: C++, Си, Objective-C, Python, Java, IDL, PHP, C#, Фортран, VHDL и, частично, D

## Установка

```sudo apt-get install doxygen graphviz```

В начале создаем файл конфигурации 

```doxygen -g Doxyfile```  - Создаем файл конфигурации Doxyfile, в котором описаны правила создания документации из комментариев к исходному коду.

Далее все последующие вызова для создания документации необходимо делать следующим образом

```doxygen Doxyfile``` - Создает документации на основе комментаривиев из исходного кода на основе правил описанных в файле Doxyfile  
По умолчанию документации создается в ```docs/html/```

## Важный параметры в файле конфигурации.

В файле конфигруации Doxyfile почти 3000 строк, а сама система поддерживает более 450 параметров (В зависимсти от версии doxygen). Для начала работы и правильного документирования достаточно настроить всего около 20-40 параметров. В файле конфигруации есть описание к каждому из параметров системы.
Основные параметры необходимы для создания документации к лабораторной работе №1

```
PROJECT_NAME           = "Мой проект"                   
PROJECT_BRIEF          = "Краткое описание проекта"  
OUTPUT_DIRECTORY       = docs  
GENERATE_LATEX         = NO  
GENERATE_HTML          = YES  
EXTRACT_ALL            = YES                    # Все объекты задокументированы
EXTRACT_PRIVATE        = YES                    # Включать ли в документацию приватные члены класса
EXTRACT_STATIC         = YES                    # Включать ли в документацию статичные элементы
INPUT                  = src include            # Где искать документировнный исходный код
FILE_PATTERNS          = *.h *.cpp *.hpp  
RECURSIVE              = YES                    # Искать ли исходные файлы в подкаталогах
```


## Правила комментирования исходного кода
### Виды комментариев
```C++
/// Однострочный комментарий
/** Многострочный комментарий */
/*! Еще один вариант многострочного комментария */
```
### Основные команды
Для описания любого части программаного кода используются следующие команды перед объявлением функции
```C++
/**
 * @brief Краткое описание функции
 * @param param1 Описание первого параметра
 * @param param2 Описание второго параметра
 * @return Описание возвращаемого значения
 * @details Подробное описание функции
 * @note Важное примечание
 * @warning Предупреждение
 */
```
### Комментирование Функций
Перед объявлением и/или определением функции вставляет блок комментариев со следующими параметрами, их можно использовать как все так и тольо необходимые.
```C++
/**
 * @brief Вычисляет сумму двух чисел
 * @param a Первое слагаемое
 * @param b Второе слагаемое
 * @return Сумма a и b
 * @exception std::invalid_argument Если параметры невалидны
 */
int add(int a, int b) {
    return a + b;
}
```

### Комментирование Класс
Пример описания класса, в начале описываем кратко класс, имя Класс, Краткое описание класса и подробное, также сделать раздел Warning и т.д.
Описания конструкторов и методов функции используются те же самые правил что и для описания функций.
```C++
/**
 * @class MyClass
 * @brief Краткое описание класса
 * 
 * Подробное описание функциональности класса
 */
class MyClass {
public:
    /**
     * @brief Конструктор по умолчанию
     */
    MyClass();
    
    /**
     * @brief Деструктор
     */
    virtual ~MyClass();
};
```

### Комментирование полей класса
Комментирование полей класса/структур происходит следующим образом с использование однострочного комментария
```C++
class Database {
private:
    int m_connectionCount;  ///< Количество активных соединений
    std::string m_hostName; ///< Имя хоста базы данных
};
```
