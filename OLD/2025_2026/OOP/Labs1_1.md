# Лабораторная работа №1 по ООП

Задана структура хранящая местоположение точек следующим образом:

```C++
struct point3d
{  
    double x,y,z;

    point3d(double x=0.0, double y=0.0, double z=0.0);          ///< Конструктор по умолчанию
    void print() const;                                         ///< Выводит на экран местоположение частицs
    double getBackX() const;                                    ///< Возращает координату X
    double getBackY() const;                                    ///< Возращает координату Y
    double getBackZ() const;                                    ///< Возращает координату Z
} 
```

Необходимо разработать класс, который будет заполнять объекты структуры случайными точками, которые находятся в некоторой области (согласно варианту). 
У класса должна быть функция
``` rnd() ``` 
которая возращает сразу все координаты точки, и заполняет один экземпляр структуры.
Структуру реализовать самостоятельно.
Для теста релизоват программу которая демонстрирует возможности класса следующим образом:
1. Заполнить случайным образом массив из K-экземпляров структуры (задается с клавиатуры, может быть как 1 точка так и 10 000 точек)
2. По запросу пользователя на экран должно быть выведено местоположение i-точки, либо любой её координаты
3. Пользователь может добавить новую точку в массив и ввести координаты точки с клавиатуры
4. Пользователь может попросить записать массив структур в файл points.txt в следующем формате:

```
x1  y1  z1  
x2  y2  z2  
x3  y3  z3  
...  
xN  yN  zN  
```  
5 Для проверки корректности области в которой задаются точки визуализировать их (можно использовать Python и matplotlib, но плюсом будет если используется библиотека для C++, например MathGL)

## Варианты работы:
Общие правила:  
пользователь, который используется созданный класс должен задать параметры области. А также иметь возможность вывести на экран параметры области и записать их в файл setting.dat
### Вариант №1
Точки заполняют облать ограниченную параллелепипедом. Важно предусмотреть вариант, когда по одной из координат может быть задан только один параметр т.е. в данном случае область будет плоская.
### Вариант №2
Точки заполняет цилиндрическую область. Важно предусмотреть вариант, когда высота цилиндра равна нулю. Т.е. точки заполняют окружность.
### Вариант №3
Точки заполняют область ограниченной поверхностью тора. 
### Вариант №4
Точки заполняют область пространства между двумя концентрическими сферами радиусов R₁ и R₂
### Вариант №5
Точки заполняют область ограниченной поверхностью конуса.
### Вариант №6
Точки заполняют область, ограниченный поверхностью верхней половины тора
### Вариант №7
Точки заполняют область, ограниченный поверхностью нижней половины тора
### Вариант №8
Точки заполняют область, ограниченную левой половиной тора
### Вариант №9
Точки заполняют область, ограниченную правой половиной тора
### Вариант №10
Точки заполняют область пространства между двумя концентрическими верхними полусферами радиусов R₁ и R₂
### Вариант №11
Точки заполняют область пространства между двумя концентрическими нижними полусферами радиусов R₁ и R₂
