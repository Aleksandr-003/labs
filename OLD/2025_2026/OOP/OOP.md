# Объектно-ориентированное программирование и проектирование

Курс разбит на два семестра:  
1 часть курса посвящена программированию  
2 часть курса посвящена проектированию  

Общие требование ко всем лабораторным работам:
1. При разработке использовать систему контроля версий GIT. Наличие осмысленых commit`ов по ходу работы обязательно. 
2. Документирование кода с использованием doxygen.
3. Реализация UML-диаграмм с использование PlantUML обязательно.
4. Понимание кода! Если не можете обяснить как работает ваша программа или для чего реализована та или иная часть программы, то работа не принимается.
