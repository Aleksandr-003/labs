### 2. Перевести CSV из ЛР№2 в Parquet
Apache Parquet — это открытый колоночно-ориентированный формат хранения данных, созданный для эффективной обработки больших массивов информации  

### 3. Разбить данные из ЛР№2 на партиции:
по месяцам:
```
data/
    sales/
        month=2019-01/
            part-0001.parquet
        month=2019-02/
            part-0001.parquet
        month=2019-03/
            part-0001.parquet
```
по неделям
```
data/
    sales/
        month=2019-01/
            week-0001.parquet
            week-0002.parquet
            week-0003.parquet
            week-0004.parquet
        month=2019-02/
            week-0001.parquet
            week-0002.parquet
            week-0003.parquet
            week-0004.parquet
        month=2019-03/
            week-0001.parquet
            week-0002.parquet
            week-0003.parquet
            week-0004.parquet
```
